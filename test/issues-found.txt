Phase III: **Dependency & External Reliance Analysis**.

### Dependency Findings

**11. Bootstrap script has privileged execution path**
```bash
[[ $(id -u) -ne 0 ]] && command -v sudo &>/dev/null && runner="sudo"
```
The script silently escalates to `sudo` if run as non-root. No warning or requirement to run with elevated privileges is documented. This is a low-severity but surprising behavior for a personal project bootstrap.

**12. CI workflow has no matrix/platform coverage**
`.github/workflows/latex.yaml` builds resume on pull requests, but there's only one job — no Ubuntu/ARM/musl testing. The `xu-cheng/latex-action@v4` action doesn't validate the autoconf layer or font availability at build time.

**13. External URL hardcoding in LaTeX**
Multiple URLs are embedded as raw strings across `_header.tex`, `fed-resume.sty`, and section files:
- `https://g.dev/franklin` (portfolio — dead link risk if domain changes)
- `https://github.com/devsecfranklin` (wrong GitHub account — see #9)
- `https://www.linkedin.com/in/franklin-diaz` (valid but no verification mechanism)
- `https://g.co/kgs/aoqdi7` (Google Maps link for color palette picker — fragile, will rot if Google changes URLs)

**14. TeX package version pins are absent**
The LaTeX source uses no `\RequirePackage` version constraints. If upstream `fontspec`, `titlesec`, or `hyperref` update with breaking API changes, builds may silently fail or produce incorrect output. No `latexmkrc` or `.texlive.texlive-version` exists to pin the TeX Live distribution.

**15. Missing `.gitignore` for build artifacts**
No gitignore rule excludes:
- `autom4te.cache/` (autoconf cache — auto-generated, should never be committed)
- `*.aux`, `*.log`, `*.fls`, `*.fdb_latexmk`, `*.synctex.gz`, `*.xdv` (TeX intermediates)
- `Makefile.in` (autotools intermediate)
- `*.pdf` (build artifact already in tree)
This bloats the repo and creates false diff noise.

### Patch 4: Lightweight Modern Makefile (Fixes #1, #2, #11)

Replacing the entire Autotools (`autoconf`, `automake`, `bootstrap.sh`) pipeline with a single portable `Makefile` removes privileged `sudo` escalation, eliminates platform-specific package managers, and simplifies local and CI builds:

```makefile
# Makefile
LATEXMK ?= latexmk
ENGINE   ?= -xelatex
OUTDIR   ?= build

SRC      := $(wildcard *.tex)
TARGETS  := $(SRC:.tex=.pdf)

.PHONY: all clean

all: $(TARGETS)

%.pdf: %.tex
	$(LATEXMK) $(ENGINE) -output-directory=$(OUTDIR) -interaction=nonstopmode -file-line-error $<
	@cp $(OUTDIR)/$@ ./$@

clean:
	rm -rf $(OUTDIR) *.pdf autom4te.cache/ Makefile.in aclocal.m4 config.log config.status configure

```
