## 1. Objective

Remove all GNU autotools build infrastructure from the franklin-resume repository and replace it with a single Go-based tool (`resumego`) that handles building, linting, testing, and deployment of the three LaTeX document trees (resume, biography, cv). This eliminates `autoreconf`, `autoconf`, `automake`, and their entire artifact set while consolidating all build logic into idiomatic Go.

## 2. Current State Analysis

### 2.1 Autotools Artifacts to Remove

| File | Location | Purpose |
|------|----------|---------|
| `configure.ac` | root | Feature detection (xelatex, latexmk, chktex, direnv), config file generation |

### 2.2 Current Build Logic (extracted from Makefile.am + bootstrap.sh)

**Root-level `make all`:** Builds `resume/resume.tex` with xelatex via latexmk, sets `TEXMFHOME`.  
**Root-level `make test`:** Runs go tests with coverage output.  
**Resume subdirectory:** `latexmk -xelatex resume.tex`  
**Biography subdirectory:** `latexmk -xelatex biography.tex` + optional `chktex` lint.  
**CV subdirectory:** `latexmk -xelatex cv.tex`  
**bootstrap.sh dependency list:** `latexmk`, `texlive-xetex`, `libpcsclite-dev`, `texlive-pictures`, `texlive-latex-extra`, `libssl-dev`, `fonts-montserrat`, `texlive-fonts-recommended`.

### 2.3 Go Module State

`go.mod` exists but is bare (`go 1.26.3`). Only the test package has go files (`test/asset_test.go`, `test/link_test.go`). No production packages exist yet.

## 3. Proposed Architecture

### 3.1 Tool: `resumego` — Single Binary

A single Go CLI tool that replaces all autotools functions plus bootstrap.sh functionality.

```
franklin-resume/
├── cmd/
│   └── resumego/
│       └── main.go          # Entry point, cobra/urf/cli-based CLI
├── internal/
│   ├── build/               # LaTeX build engine
│   │   ├── latexmk.go       # Wraps latexmk invocations with error handling
│   │   ├── chktex.go        # Optional lint integration
│   │   └── texmf.go         # TEXMFHOME path resolution
│   ├── deploy/              # GitHub Pages / publishing logic
│   │   └── publish.go       # SCP/Sync to wonderland web root
│   ├── audit/               # Doc integrity checks
│   │   ├── links.go         # Internal link validation
│   │   └── images.go        # Image reference completeness
│   └── deps/                # Dependency detection (replaces AC_CHECK_PROG)
│       └── probe.go         # Detects xelatex, latexmk, chktex availability
├── pkg/
│   └── config/              # Project-wide config types
│       └── config.go        # Doc targets, paths, flags
├── resume/                  # Existing — unchanged
│   ├── resume.tex
│   └── ...
├── biography/               # Existing — unchanged
│   ├── biography.tex
│   └── ...
├── cv/                      # existing — unchanged
│   ├── cv.tex
│   └── ...
├── go.mod                   # Existing — updated with dependencies
├── go.sum                   # Generated by Go toolchain
├── Makefile                 # Thin wrapper: go run ./cmd/resumego $@
├── README.md                # Updated build instructions
├── BUILD.md                 # Existing — update reference
└── .envrc                   # Update direnv exports if needed
```

### 3.2 CLI Interface (cobra-based)

```
resumego build [target]          # Build one or all documents
resumego clean [target]          # Clean build artifacts
resumego lint [target]           # Run chktex on specified document
resumego test                    # Run Go test suite with coverage
resumego check-deps              # Probe system for required tools (replaces AC_CHECK_PROG)
resumego install-deps            # Install missing Debian deps (replaces bootstrap.sh install_deps)
resumego publish [target]        # Deploy to wonderland web root via SCP
resumego audit                   # Full doc integrity scan (links, images, references)
```

Targets: `resume`, `biography`, `cv`, or omitted for all.

### 3.3 Go Module Dependencies

| Package | Purpose |
|---------|---------|
| `github.com/spf13/cobra` | CLI framework |
| `github.com/otiai10/copy` | File copy utilities (publish) |
| `golang.org/x/sync` | Parallel document building |

No external runtime dependencies beyond Go stdlib for core logic. All LaTeX tooling wraps system binaries (latexmk, xelatex, chktex).

## 4. Migration Plan

### Phase 1: Write `resumego` (parallelizable)

**Step 1a.** Implement `internal/deps/probe.go` — replaces all `AC_CHECK_PROG` logic from `configure.ac`.

```go
type Probe struct {
    XeLaTeX   bool `json:"xelatex"`
    Latexmk   bool `json:"latexmk"`
    ChkTex    bool `json:"chktex,omitempty"`
    Direnv    bool `json:"direnv,omitempty"`
}

func (p *Probe) AllMet() bool { ... }  // xelatex + latexmk required
func (p *Probe) Missing() []string { ... }
```

**Step 1b.** Implement `internal/build/latexmk.go` — deterministic wrapper around system latexmk with proper error capture, exit code handling, and TEXMFHOME injection. Replaces all three subdirectory Makefile rules plus root Makefile rules.

**Step 1c.** Implement `internal/deps/probe.go` install-deps path using `os/exec` to run `apt-get` with the same dependency list from bootstrap.sh (`DEB_PKG` array).

### Phase 2: Wire CLI (parallelizable with Step 1)

**Step 2a.** Create `cmd/resumego/main.go` with cobra root + subcommands for all targets.

**Step 2b.** Implement `resumego build`, `clean`, `lint`, `test`, `check-deps`, `install-deps`.

**Step 2c.** Implement `internal/deploy/publish.go` — SCP deployment to wonderland (`178.62.60.55`) using `os/exec` of `scp` or `sftp`. Same destinations as the existing GitHub Actions workflow.

### Phase 3: Integrate and Validate

**Step 3a.** Update root `Makefile` to delegate everything to `go run ./cmd/resumego`.

**Step 3b.** Ensure `resumego test` produces identical output to existing `make test` (coverage.out, coverage.html).

**Step 3c.** Parallel build all three documents (`resume`, `biography`, `cv`) and verify PDFs match or improve on current output.

### Phase 4: Purge Autotools

**Step 4a.** Delete all autotools artifacts (see Section 2.1 inventory).

| Files to delete |
|-----------------|
| `configure.ac` |
| `bootstrap.sh` |
| `Makefile.am` (all 4 copies: root, resume/, biography/, cv/) |

### Phase 5: Verify GitHub Actions

**Step 5a.** Review `.github/workflows/latex.yaml` — ensure it can invoke `go run ./cmd/resumego` or the compiled binary. Replace any autotools-specific steps (e.g., `./bootstrap.sh`, `autoreconf`, `./configure`).

**Step 5b.** Update Docker/build image if the CI workflow uses a base image that installs autotools — remove those deps.

## 5. Comparison: Autotools vs `resumego`

| Concern | Autotools (current) | `resumego` (proposed) |
|---------|---------------------|------------------------|
| **Build system dependency** | autoconf >= 2.71, automake, autoreconf | Go toolchain only (`go install`) |
| **Install complexity** | bootstrap.sh: apt deps + autoreconf + configure | `resumego install-deps` (optional, one-liner) |
| **Feature detection** | AC_CHECK_PROG in configure.ac at config time | `resumego check-deps` at runtime |
| **Artifact count** | 10+ files (configure.ac, Makefile.am×4, Makefile.in×4, config/, etc.) | 3 source dirs + go.mod/go.sum only |
| **Cross-platform** | Linux-centric (dpkg, apt-get) | Go stdlib cross-compile; deps probe is platform-aware |
| **Build parallelism** | Sequential via `make` | `golang.org/x/sync/errgroup` for parallel PDF builds |
| **Determinism** | Config-time detection, non-deterministic paths | Runtime probe, explicit path resolution |
| **Test coverage** | External Go tests only | Go tests + LaTeX link audit integrated |
| **Maintenance burden** | M4 macro language, autoreconf magic | Idiomatic Go, `go vet`, `go fmt` |

## 6. Risk Assessment

| Risk | Mitigation |
|------|-----------|
| Existing CI/CD depends on autotools | Audit `.github/workflows/latex.yaml` before Phase 4; update in Phase 5 |
| Go toolchain not installed on target build hosts | Provide a pre-compiled binary via release artifact, or add Go to base Docker image |
| Loss of `chktex` lint integration (biography/) | Implemented as optional `resumego lint` — chktex detected at runtime just like AC_CHECK_PROG did |
| TEXMFHOME path hardcoding (`~/workspace/texmf`) | Config file or environment variable override in `pkg/config`; probe for TeX user tree |
